# 洗小猪

竖屏洗猪试玩。模型是 Grab3D 的写实家猪（CC0），页面是静态的，不连服务器。

线上：https://bruceyu08-droid.github.io/realistic-pig-preview/

## 玩法

- 按住并拖动：水从枪头喷出。水速可选弱、中、强、劲，越强冲得越快，水花和皮肤下陷也越明显。
- 泡沫：先喷在身上，再换清水，把泡沫和剩下的泥一起冲掉。
- 水箱够用一整局，喷涂时会减少。
- 双指转动、捏合缩放。鼠标右键转动，滚轮缩放。点「看肚皮」可以转到肚子下面冲洗。
- 偶尔会张一下嘴，并响起一段合成的哼叫。
- 洗到足够干净后可以再来一次。

小猪会自己眨眼、轻轻转眼、偶尔抖一下耳朵，胸口和肚子有很浅的呼吸，站着时有一点重心移动。水打到身上时，只有击中的那一小块轻微陷下去，很快回正。肚皮和腮帮仍只保留原来那种很轻的软组织滞后，不会变成果冻。

## 本地打开

不要直接双击 `index.html`。在本目录启动静态服务器：

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

然后打开 http://127.0.0.1:8080/
